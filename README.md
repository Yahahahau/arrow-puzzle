# Arrow Puzzle

เกมปริศนาลูกศร 2D (HTML + CSS + JavaScript ล้วน ไม่มี library ภายนอก) ออกแบบแนวตั้งสำหรับมือถือ
รองรับ **ซูมเข้า/ออกด้วยสองนิ้ว (pinch)**, **ลากเลื่อน (pan) พร้อมแรงเฉื่อย**, ฝังผ่าน `<iframe>` และ WebView ของ Android / iOS

## วิธีเล่น
- แตะลูกศรเพื่อให้ลูกศรเลื่อนออกตามทิศที่หัวชี้ — ถ้าเส้นทางว่างจะเลื่อนออกจากกระดาน
- ถ้ามีลูกศรอื่นขวางอยู่ ลูกศรจะสั่น/แดงและเสีย 1 ชีวิต (แคปซูล 3 อัน) ลูกศรที่ขวางจะกะพริบสีส้ม
- เอาลูกศรออกให้หมดเพื่อผ่านด่าน
- **ซูม:** บีบ/ถ่างสองนิ้ว (เมาส์: ล้อเลื่อน)  **เลื่อน:** ลากนิ้วเดียว  ปุ่มมุมขวาบนของกระดานจะย่อให้พอดีจอ
- 💡 คำใบ้: ไฮไลต์ลูกศรที่ออกได้ 1 ตัวและเลื่อนกล้องไปหา (3 ครั้ง/ด่าน)
- 📏 ไม้บรรทัด: แสดงเส้นทางของลูกศรทุกตัวชั่วคราว เขียว = ออกได้, แดง = มีตัวขวาง (3 ครั้ง/ด่าน)
- แท็บ **คำท้า**: คำท้าประจำวัน (สุ่มจากวันที่) พร้อมปฏิทินย้อนหลัง, แท็บ **ฉัน**: สถิติ ตั้งค่าเสียง/สั่น ล้างข้อมูล
- ความคืบหน้าบันทึกใน `localStorage` (ถ้าใช้ไม่ได้ เกมยังเล่นได้ แต่ไม่บันทึก)

## โครงสร้างโฟลเดอร์
```
arrow-puzzle/
├─ index.html            หน้าเกม (ทุกหน้าจออยู่ในไฟล์เดียว)
├─ embed-example.html    ตัวอย่างฝังผ่าน iframe หลายขนาด
├─ netlify.toml          ตั้งค่า deploy + อนุญาตให้ถูกฝัง (frame-ancestors *)
├─ css/style.css         UI ทั้งหมด (ขนาดอิงตัวแปร --u) + สีพื้น/เงา/ฮาล์ฟโทนของแผงวาดมือ
├─ css/themes.css        สีทุกธีม (Light / Dark / Custom) ใช้ร่วมกับ canvas
├─ js/
│  ├─ engine.js          กติกา: Board, occupancy grid, เส้นทางออกแบบแคช, validate/isSolvable
│  ├─ levels.js          ข้อมูลด่าน + ตัวสร้างด่านอัตโนมัติ (แก้ได้แน่นอน)
│  ├─ dotmap.js          Dot Map แผนที่จุดซิงก์กับ grid จริง
│  ├─ sketch.js          แผง/ปุ่มทรงวาดมือ + เส้นขอบ 4 เฟรมสลับที่ 12 FPS
│  ├─ view.js            กล้อง: pinch-zoom, pan, momentum, wheel, tween
│  ├─ game.js            state, animation (rAF + delta time), เรนเดอร์ Canvas 2D
│  ├─ audio.js           เสียง WebAudio สังเคราะห์ (ไม่มีไฟล์เสียง)
│  ├─ storage.js         บันทึกความคืบหน้า
│  └─ main.js            หน้าจอ, HUD, modal, ผูกปุ่ม, ResizeObserver
├─ assets/icon.svg
└─ tools/verify-levels.js  สคริปต์ตรวจว่าทุกด่านแก้ได้ (node)
```

## รันบนเครื่อง
ไม่ต้อง build เปิด `index.html` ได้เลย หรือรันเซิร์ฟเวอร์ static:
```bash
cd arrow-puzzle
npx serve .        # หรือ python3 -m http.server 8080
```
เปิดด่านใดด่านหนึ่งตรง ๆ เพื่อทดสอบ: `index.html?level=24`

## Deploy (Netlify / Static Hosting)
ลากทั้งโฟลเดอร์ไปวางที่ Netlify Drop หรือ `netlify deploy --dir=. --prod`
(`netlify.toml` ตั้ง `frame-ancestors *` ไว้แล้ว เพื่อให้แอปอื่นฝังได้ — ถ้าต้องการจำกัดโดเมน ให้แก้ค่านี้)
GitHub Pages / Cloudflare Pages / S3 ใช้ได้เหมือนกัน เพียงอัปโหลดไฟล์ทั้งหมด

## ฝังผ่าน iframe
```html
<iframe
  src="https://your-game-url.example/"
  style="width:100%;height:100%;border:0;"
  allow="autoplay"
></iframe>
```
- เกมวัดขนาดจาก **พื้นที่ของ iframe เอง** (ResizeObserver บน `#app` และพื้นที่กระดาน) ไม่ใช่ขนาดหน้าจออุปกรณ์ — ปรับขนาด iframe แล้วเกมจัด layout ใหม่ทันทีโดยคงตำแหน่งซูม
- ไม่ใช้ Fullscreen API, popup, redirect หรือเข้าถึง `window.parent`
- ใช้ Pointer Events + `touch-action:none` บนกระดาน จึงไม่ทำให้หน้าเว็บภายนอกเลื่อนตอนเล่น; ไม่มี horizontal overflow; รองรับ Safe Area (`viewport-fit=cover`)
- WebView ของแอป: ต้องเปิด JavaScript และ DOM storage (`setDomStorageEnabled(true)` บน Android) ถ้าต้องการบันทึกความคืบหน้า

## เพิ่มด่านเอง
แก้ `CUSTOM_LEVELS` ใน `js/levels.js` — แต่ละลูกศรคือรายการช่อง `[col,row]` เรียงจากหางไปหัว ทิศหัวคือทิศของก้าวสุดท้าย
```js
CUSTOM_LEVELS = {
  1: { cols: 5, rows: 5, arrows: [
        [[0,0],[1,0],[2,0],[3,0]],     // ชี้ขวา
        [[0,1],[1,1],[1,2]]            // เลี้ยวแล้วชี้ลง
  ] }
};
```
ด่านที่ไม่ได้กำหนดจะถูกสร้างอัตโนมัติจาก seed (ยากขึ้นตามเลขด่าน: กระดานใหญ่ขึ้นสูงสุด 28×29 และลูกศรยาวขึ้น)
ตัวสร้างด่านวางลูกศรตามลำดับ "นำออก" จึงแก้ได้เสมอ ตรวจซ้ำได้ด้วย
```bash
node tools/verify-levels.js 150
```
ปรับค่าความยากที่ฟังก์ชัน `params(n)`; ปรับจำนวนชีวิต/คำใบ้/ไม้บรรทัดและความเร็วอนิเมชันที่ค่าคงที่บนสุดของ `js/game.js`

## ระบบ Animation ลูกศร
- **เส้นทางต่อเนื่อง ไม่หยุดกลางทาง**: เร่งออกตัวแบบ smoothstep 70ms → วิ่งด้วยความเร็วคงที่ → ผ่อนความเร็วเบา ๆ ในช่วง 40% สุดท้ายลงเหลือ ~55% (ไม่เคยหยุด) ความเร็วเดินทาง ≈ 1010 px/วินาที (รอบนี้ช้าลง ~28% จาก 1400; `SPEED_PX` ใน `js/game.js`) และ **ระยะเวลาปรับตามระยะทาง** — วัดระยะจากหัวลูกศรถึงขอบพื้นที่แสดงผลจริง ณ ตอนแตะ (ตัวอย่าง: 317–533ms ตามระยะ)
- **ไม่ Fade / ไม่ย่อขนาด** opacity = 1 และรูปร่างเดิมตลอดจนพ้นจอ
- **ออกจนพ้นหน้าจอจริง**: ใช้ Animation Layer แยก (`<canvas id="fx">` คลุมทั้งแอป) ไม่ถูกตัดโดยกระดาน; ลบลูกศรเมื่อ *ทั้งตัว* พ้นพื้นที่แสดงผล (ถ้าผู้เล่นเลื่อนกล้องระหว่างบิน ระบบเช็กกับมุมมองปัจจุบันอีกครั้ง)
- ใช้ timestamp ของ `requestAnimationFrame` จึงไม่ขึ้นกับ Refresh Rate; กระดานหลักวาดซ้ำเฉพาะเมื่อมีอะไรเปลี่ยน
- สถานะ animation แยกต่อลูกศร: แตะซ้ำระหว่างบินถูกเมินเฉย, Restart / ออกจากด่าน = ยกเลิกทันทีและล้าง layer
- Occupancy grid (`engine.js`): แคช "เส้นทางออก" ของแต่ละลูกศรไว้ล่วงหน้า อัปเดต grid ทันทีที่ปล่อยลูกศร

## Dot Map (แผนที่จุด)
มุมซ้ายของแถบเครื่องมือ: จุด 1 จุดต่อ 1 ช่องของกระดาน เรียงแถว/คอลัมน์ตรงกับกระดานจริง สีของจุดมาจาก state จริงของ Board (`js/dotmap.js`):
- **น้ำเงิน** = ลูกศรที่ออกได้ตอนนี้ (Available) · **เทาม่วง** = ถูกบัง (Blocked) · **จางเล็ก** = นำออกแล้ว (Removed) · จุดเล็กมาก = ช่องว่าง
- เปลี่ยนสถานะด้วยการไล่สี/ขนาดนุ่ม ๆ (~250ms) และเมื่อซูมเข้า จะมีกรอบสี่เหลี่ยมบอกบริเวณที่กำลังมองอยู่
- จุดนิ่งวาดไว้ใน offscreen canvas วาดซ้ำเฉพาะตอนสถานะเปลี่ยน

## UI / Motion
- โทเค็นเวลา: UI 240ms · กดลง 130ms · คืนตัว 300ms · แผง/หน้าจอ 300ms (ตัวแปร `--t-*` ใน `css/style.css`)
- ปุ่มทั้งหมดใช้ระบบเดียวกัน: กดแล้วยุบเป็น scale .96 ทันที (ผ่าน Pointer Events ค้างอย่างน้อย 90ms แม้แตะเร็ว) ปล่อยแล้วเด้งกลับพร้อม overshoot เล็กน้อยครั้งเดียว
- แสงสะท้อน: แถบ gloss บาง ๆ บนปุ่ม/การ์ด + ไฮไลต์ขอบ; บนเดสก์ท็อป (hover) มีแสงตามเมาส์และปุ่มยกขึ้นเล็กน้อย มือถือใช้ความรู้สึกตอนกดแทน
- ไอคอนทั้งหมดเป็น SVG (เฟืองตั้งค่าสมมาตร 8 ฟัน, หัวใจ 3 ดวงแบบเดิม), เส้นไอคอนหนา 2.4 เท่ากัน, ไม่ใช้ emoji/Unicode แทนไอคอน
- ปรับด้วย Transform/Opacity เป็นหลัก; รองรับ `prefers-reduced-motion`

## Developer Mode
เปิดด้วย `?dev=1` หรือแตะชื่อด่านบนหัวเกม 5 ครั้งติดกัน (ปิดด้วยปุ่ม ×)
- **perf**: FPS ปัจจุบัน/เฉลี่ย, Frame time (ms), Refresh Rate ที่ตรวจจับได้, Dropped frames, สถานะ animation, จำนวนลูกศรที่กำลังบิน (ปิด/เปิดได้)
- **grid**: Debug Occupancy Grid — เทา = ว่าง, น้ำเงิน = มีลูกศร, แดง = เส้นทางถูกบัง, เขียว = เส้นทางที่ออกได้
- ปิดอยู่เสมอในการเล่นปกติ และไม่ทำงานเมื่อไม่ได้เปิด

ปรับความเร็ว/ระยะ overshoot ได้ที่ค่าคงที่บนสุดของ `js/game.js` (`SPEED_PX`, `RAMP`, `EXIT_MARGIN`)

## หมายเหตุด้านเทคนิค
- เรนเดอร์ Canvas 2D; ลูกศรปกติถูกวาดรวมใน path เดียว จึงลื่นแม้ 150+ ลูกศร และตัดส่วนที่อยู่นอกจอ
- ลูปอนิเมชันหลับเมื่อไม่มีอะไรขยับ และหยุดเมื่อแท็บอยู่เบื้องหลัง (กลับมาเล่นต่อได้ปกติ)
- ไม่มี `setInterval`/`setTimeout` ขับ animation (ใช้ `setTimeout` เฉพาะหน่วงการเปิด modal)
- ตอนติดขวาง: ลูกศรสั่นเป็นสีแดงพร้อมสั่นเครื่อง (ถ้ารองรับ)


## ธีม / ภาษา / Confetti (รอบ 4)
- **ธีม**: `css/themes.css` ใช้ CSS variables ทั้งหมด — Light (ค่าเริ่มต้น), Dark, Custom ("Sunset") เลือกได้ใน Settings; สีบนแคนวาส (ลูกศร จุด Dot Map confetti) อ่านจากตัวแปรเดียวกัน จึงตามธีมเสมอ สคริปต์ pre-paint ใน `index.html` ตั้งธีมก่อนวาดหน้าแรก จึงไม่กะพริบ
  แก้ธีม Custom ได้ที่บล็อก `[data-theme="custom"]` หรือตอนรันไทม์: `ArrowPuzzle.setCustomTheme({'--accent':'#e0457b','--ink':'#3a1230'})` (บันทึกใน localStorage)
- **ภาษา**: อังกฤษเป็นค่าเริ่มต้น ข้อความทั้งหมดอยู่ใน `js/i18n.js` (เพิ่มภาษาโดยคัดลอกบล็อก `en`) มีภาษาไทยให้เลือกใน Settings; HTML ใช้ `data-i18n` / `data-i18n-aria`
- **Music**: เพลงพื้นหลังสังเคราะห์ด้วย WebAudio (ไม่มีไฟล์เสียง) ค่าเริ่มต้นปิด
- **ลูกศร**: hover (ขยาย 3.5% + ยกขึ้นเล็กน้อย + เรืองแสง, เฉพาะเมาส์), กด (หดเหลือ ~93% แล้วเด้งกลับด้วย spring ต่อเนื่องเข้าสู่การเคลื่อนที่), ลูกศรที่ถูกขวางสั่นเบา ๆ — ทั้งหมดเป็นการวาดอย่างเดียว ไม่แตะตำแหน่งกริดหรือการชน
- **Confetti**: แคนวาส `#confetti` แยกต่างหาก ~60 ชิ้น ร่วงจากขอบบน มีแรงโน้มถ่วง/ความเร็วปลายทาง/การส่าย/การหมุนต่างกัน ใช้เวลา ~3.3 วินาที ไม่ fade กลางจอ และเล่นต่อได้ตอน panel ชนะขึ้น (panel เข้า ~450ms หลังชนะ)
- **Timing**: ตัวแปร `--t-ui` 280ms, `--t-press` 150ms, `--t-panel` 350ms, `--t-win` 420ms ใน `css/style.css`

## รอบ 5: ชน-ถอย, จุดบนกระดาน, แท็บเล็ต/แนวนอน
- **ชนแล้วถอย**: แตะลูกศรที่ถูกขวาง ลูกศรจะวิ่งตามเส้นทางของตัวเองไปจนปลายแตะลูกศรที่ขวาง → เสียหัวใจตอนชน (ลูกศรเป็นสีแดง ตัวที่ขวางกะพริบส้ม) → พักสั้น ๆ แล้วถอยกลับแบบ ease-in-out (0.34–0.7 วินาทีตามระยะ) กริด/การชนไม่เปลี่ยน
- **จุดบนกระดาน**: ช่องที่มีลูกศรจะไม่มีจุด จุดจะเกิดทีละช่องเมื่อหางลูกศรผ่านพ้นช่องนั้นไปแล้วจริง ๆ พร้อมอนิเมชันเด้ง (damped spring) ส่วนช่องว่างตอนเริ่มด่านเด้งขึ้นจากกลางกระดานออกไป
- **เริ่มด่าน**: ลูกศรเด้งขึ้นมาจากกลางกระดานออกไปทีละชั้น (ปิดอัตโนมัติเมื่อเครื่องตั้ง reduced-motion)
- **แท็บเล็ต/แนวนอน**: `main.js` ตั้ง `data-orient="land"` เมื่อกว้างกว่าสูง 1.15 เท่า — หน้าเกมแบ่งเป็นแผงซ้าย (ชื่อด่าน/จำนวน/หัวใจ/ความยาก) กระดานตรงกลาง และแผงขวา (Dot Map/คำใบ้/ไม้บรรทัด); หน้าแรกจัดการ์ดคู่กับปุ่ม; หน้าต่างตั้งค่าแบ่ง 2 คอลัมน์ ขนาด UI (`--u`) จำกัดไม่เกิน 5.2px จึงไม่ใหญ่เกินบน iPad ทดสอบที่ 390×844, 844×390, 820×1180, 1180×820, 1440×900 ไม่มีส่วนใดซ้อนกันหรือล้นจอ

## รอบ 6: Black wipe transition
- `js/transition.js` — ตัวจัดการกลาง `AP.Transition.run(changeFn, { dir })`: แผงดำสนิท (#000) เลื่อนเข้าจากขวา 360ms → เปลี่ยนฉาก/ด่านตอนจอดำเต็ม → รอ 2 เฟรมให้หน้าใหม่วาดเสร็จ → เลื่อนต่อออกทางซ้าย 420ms (รวม ~800ms) ใช้ `translate3d` + cubic-bezier ไม่มีเด้งเกิน
- ใช้กับ: Continue/Play/วันในปฏิทิน → เกม, Next Level / กลับไปที่คำท้า, Restart (ด่านใหม่), Home, สลับแท็บ Home/Challenges/Profile (หน้า Settings) — หน้าต่างเล็ก (Pause/Confirm) ไม่ใช้
- กันกดซ้อน: ระหว่าง wipe แผงดำบังอินพุตทั้งหมด และคำขอที่ซ้ำจะถูกปฏิเสธ (`run` คืน `false`); ถ้าการเปลี่ยนฉากเกิด error จะ log แล้วเปิดจอกลับเสมอ ไม่ค้างดำ
- ทิศทาง: `left` (ค่าเริ่มต้น ขวา→ซ้าย), `right`, `up`, `down` เช่น `ArrowPuzzle.transition(fn, 'up')`; ตั้ง reduced-motion แล้วสั้นลงเหลือ ~240ms
- แผงอยู่ใน `#app` จึงครอบเฉพาะพื้นที่เกมจริง (รวมใน iframe) ไม่ได้อิงขนาดจอเครื่อง

## รอบ 7: ตรวจจับอัปเดตอัตโนมัติ + motion blur แกน X
- **อัปเดตอัตโนมัติ** (`js/update.js`, แบบเดียวกับ Pixel Cash Factory): ทุก deploy เขียน `version.json` และฝังเลขเวอร์ชันเดียวกันใน `<meta name="app-version">` ของ `index.html` (ไฟล์ CSS/JS ทุกไฟล์โหลดด้วย `?v=<เวอร์ชัน>` จึงไม่ปนกับแคชเก่า)
  - เกมเช็ก `version.json` ทุก 45 วินาที, ตอนกลับมาที่แท็บ, ตอนกลับมาออนไลน์ และ 4 วินาทีหลังเปิด
  - เจอเวอร์ชันใหม่ → ส่ง `postMessage` `arrow-puzzle:updateAvailable` ให้หน้าที่ฝัง iframe → รอจังหวะปลอดภัย (ไม่ตัดกลางด่าน: ถ้าอยู่ในเกมจะรอจนกด Home/Next Level/Restart; ถ้าอยู่หน้าเมนูจะอัปเดตทันที) → แผงดำเลื่อนปิดจอ → จำหน้าที่อยู่ → รีโหลด → หน้าใหม่เริ่มดำแล้วเลื่อนเปิดกลับมาที่หน้าเดิม
  - หน้าที่ฝังสั่งได้: `iframe.contentWindow.postMessage({target:'arrow-puzzle', type:'arrow-puzzle:checkUpdate'}, '*')` หรือ `'arrow-puzzle:reload'`; เกมส่ง `arrow-puzzle:ready` / `updateAvailable` / `reloading`
  - กันลูป: รีโหลดเวอร์ชันเดียวกันได้ไม่เกิน 2 ครั้งต่อ session; เปิดผ่าน `file://` หรือเวอร์ชัน `dev` จะไม่เช็ก
  - **การออกเวอร์ชัน**: Netlify รัน `node tools/stamp-version.js` ให้อัตโนมัติ (ใช้ commit id); โฮสต์แบบไม่มี build (เช่น GitHub Pages ธรรมดา) ให้รันคำสั่งนี้ก่อน commit ทุกครั้ง
- **Motion blur แกน X**: แผงดำมี "ปีก" ไล่เฉดนุ่ม ๆ ที่ขอบซ้าย/ขวา กว้างตามความเร็ว (สูงสุด 22% ของความกว้างจอ, กว้างสุดตอนเลื่อนเร็ว แคบลงตอนชะลอ) เบลอเฉพาะแนวนอน ตัวแผงทึบยังกว้าง 100% จึงดำสนิทตอนเปลี่ยนฉาก ใช้ Web Animations + `transform` อย่างเดียว

## รอบ 8: UI วาดมือสไตล์การ์ตูน + เส้นขอบ 12 FPS
- **ภาษาภาพใหม่**: เส้นขอบดำหนา, แผงสี่เหลี่ยมเบี้ยวเล็กน้อย (มุมแต่ละมุมไม่เท่ากัน), สีพื้นเรียบสด (เขียว/เหลือง/ฟ้า/ขาว/ดำ), จุดฮาล์ฟโทนแบบการ์ตูนช่อง, เงาพิมพ์ทึบแทนเงาเบลอ, ตัวหนังสือขาวขอบดำบนปุ่มหลัก
- **`js/sketch.js`**: ทุก element ที่มี `data-sk="<ชนิด>"` จะได้ `<svg class="sk">` ข้างหลัง (พื้น + ฮาล์ฟโทน + เงา + เส้นขอบ 4 เฟรม) รูปทรง seed ตามแต่ละชิ้น สร้างใหม่เฉพาะตอนขนาดเปลี่ยน (ResizeObserver) และจับ element ใหม่อัตโนมัติ (MutationObserver)
  - ตัวเลือก: `data-sk-bleed="ltrb"` (ยืดเกินขอบด้านนั้น), `data-sk-amp="1.5"` (ความเบี้ยว), `data-sk-seed="3"`
  - **12 FPS**: เส้นขอบ 4 แบบที่คำนวณไว้แล้ว สลับด้วย CSS `steps()` (รอบละ 333ms = 12 เฟรม/วินาที) ไม่มี timer JS ไม่เขียน DOM ทุกเฟรม และแยกจาก rAF ของเกม — วัดได้: เส้นขอบ 12.5 ครั้ง/วินาที, เกม 60 FPS (p95 16.8ms) ระหว่างลูกศรวิ่ง; `prefers-reduced-motion` จะหยุดที่เฟรมเดียว
  - ปรับสี/เงาต่อชนิดได้ใน `style.css` ผ่านตัวแปร `--sk-fill`, `--skw` (ความหนาเส้น), `--sk-dx/--sk-dy` (ระยะเงา)
- **ไอคอนวาดใหม่ทั้งหมด** (SVG เส้นหนา ไม่ใช้ emoji): ย้อนกลับ, หยุดชั่วคราว (สองแท่ง), ตั้งค่า (เฟือง), เล่น, เริ่มใหม่ (ลูกศรวน), เสียง (ลำโพง), เพลง, สั่น, ธีม, ภาษา, หลอดไฟ, ไม้บรรทัด, ปฏิทิน, แท็บ, เหรียญชนะ, ไอคอนแพ้ และมิเตอร์ระดับความยาก — **เอาหัวใจออกทั้งหมด** ชีวิตเป็นเหรียญสี่เหลี่ยมวาดมือ 3 อัน
- **ลูกศรใหม่** (`game.js`, วาดอย่างเดียว): ขอบดำหนา + ตัวสีเหลือง, หัวแบบลูกดอกมีรอยบาก เบี้ยวเล็กน้อยแบบ seed ต่อลูก (ไม่กระพริบ); hover = ขยาย + เอียง + ไฮไลต์เขียว, กด = บีบตามแนวลูกศร, ชน = สั่นสั้น ๆ + สีแดง แล้วถอยกลับ
  - ไม่แตะระบบเคลื่อนที่/ชน: `SPEED_PX`, `HEAD_LEN`, `_pick`, `blocker`, จุดชน และ `engine.js` / `levels.js` / `view.js` เหมือนเดิมทุกบรรทัด ปลายหัว (รวมขอบ) จบตรงจุดเดิมบน grid
- **ธีม**: Light (ขาว/ดำ/เขียว), Dark (พื้นเข้ม เส้นชอล์ก), Custom (Sunset) ใช้ภาษาภาพเดียวกัน; สีลูกศรอ่านจาก `--arrow-fill` / `--ink`
- **Black wipe** ยังเป็นแผงดำเต็มจอเหมือนเดิม; ปีก motion blur เปลี่ยนเป็นจุดฮาล์ฟโทนจาง ๆ และขอบแผงเป็นรอยหยักวาดมือ
