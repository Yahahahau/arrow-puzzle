# Arrow Puzzle

เกมปริศนาลูกศร 2D (HTML + CSS + JavaScript ล้วน ไม่มี library ภายนอก) ออกแบบแนวตั้งสำหรับมือถือ
รองรับ **ซูมเข้า/ออกด้วยสองนิ้ว (pinch)**, **ลากเลื่อน (pan) พร้อมแรงเฉื่อย**, ฝังผ่าน `<iframe>` และ WebView ของ Android / iOS

## วิธีเล่น
- แตะลูกศรเพื่อให้ลูกศรเลื่อนออกตามทิศที่หัวชี้ — ถ้าเส้นทางว่างจะเลื่อนออกจากกระดาน
- ถ้ามีลูกศรอื่นขวางอยู่ ลูกศรจะสั่น/แดงและเสีย 1 หัวใจ (มี 3 ดวง) ลูกศรที่ขวางจะกะพริบสีส้ม
- เอาลูกศรออกให้หมดเพื่อผ่านด่าน
- **ซูม:** บีบ/ถ่างสองนิ้ว (เมาส์: ล้อเลื่อน)  **เลื่อน:** ลากนิ้วเดียว  ปุ่มมุมขวาบนของกระดานจะย่อให้พอดีจอ
- 💡 คำใบ้: ไฮไลต์ลูกศรที่ออกได้ 1 ตัวและเลื่อนกล้องไปหา (3 ครั้ง/ด่าน)
- 📏 ไม้บรรทัด: แสดงเส้นทางของลูกศรทุกตัวชั่วคราว เขียว = ออกได้, แดง = มีตัวขวาง (3 ครั้ง/ด่าน)
- แท็บ **คำท้า**: คำท้าประจำวัน (สุ่มจากวันที่) พร้อมปฏิทินย้อนหลัง, แท็บ **ฉัน**: สถิติ ตั้งค่าเสียง/สั่น ล้างข้อมูล
- ความคืบหน้าบันทึกใน `localStorage` (ถ้าใช้ไม่ได้ เกมยังเล่นได้ แต่ไม่บันทึก)

## โครงสร้างโฟลเดอร์
```
arrow-puzzle/
├─ index.html            หน้าเกม (ทุกหน้าจออยู่ในไฟล์เดียว)
├─ embed-example.html    ตัวอย่างฝังผ่าน iframe หลายขนาด
├─ netlify.toml          ตั้งค่า deploy + อนุญาตให้ถูกฝัง (frame-ancestors *)
├─ css/style.css         UI ทั้งหมด (ขนาดอิงตัวแปร --u)
├─ js/
│  ├─ engine.js          กติกา: Board, ตรวจสิ่งกีดขวาง (ray), validate/isSolvable
│  ├─ levels.js          ข้อมูลด่าน + ตัวสร้างด่านอัตโนมัติ (แก้ได้แน่นอน)
│  ├─ view.js            กล้อง: pinch-zoom, pan, momentum, wheel, tween
│  ├─ game.js            state, animation (rAF + delta time), เรนเดอร์ Canvas 2D
│  ├─ audio.js           เสียง WebAudio สังเคราะห์ (ไม่มีไฟล์เสียง)
│  ├─ storage.js         บันทึกความคืบหน้า
│  └─ main.js            หน้าจอ, HUD, modal, ผูกปุ่ม, ResizeObserver
├─ assets/icon.svg
└─ tools/verify-levels.js  สคริปต์ตรวจว่าทุกด่านแก้ได้ (node)
```

## รันบนเครื่อง
ไม่ต้อง build เปิด `index.html` ได้เลย หรือรันเซิร์ฟเวอร์ static:
```bash
cd arrow-puzzle
npx serve .        # หรือ python3 -m http.server 8080
```
เปิดด่านใดด่านหนึ่งตรง ๆ เพื่อทดสอบ: `index.html?level=24`

## Deploy (Netlify / Static Hosting)
ลากทั้งโฟลเดอร์ไปวางที่ Netlify Drop หรือ `netlify deploy --dir=. --prod`
(`netlify.toml` ตั้ง `frame-ancestors *` ไว้แล้ว เพื่อให้แอปอื่นฝังได้ — ถ้าต้องการจำกัดโดเมน ให้แก้ค่านี้)
GitHub Pages / Cloudflare Pages / S3 ใช้ได้เหมือนกัน เพียงอัปโหลดไฟล์ทั้งหมด

## ฝังผ่าน iframe
```html
<iframe
  src="https://your-game-url.example/"
  style="width:100%;height:100%;border:0;"
  allow="autoplay"
></iframe>
```
- เกมวัดขนาดจาก **พื้นที่ของ iframe เอง** (ResizeObserver บน `#app` และพื้นที่กระดาน) ไม่ใช่ขนาดหน้าจออุปกรณ์ — ปรับขนาด iframe แล้วเกมจัด layout ใหม่ทันทีโดยคงตำแหน่งซูม
- ไม่ใช้ Fullscreen API, popup, redirect หรือเข้าถึง `window.parent`
- ใช้ Pointer Events + `touch-action:none` บนกระดาน จึงไม่ทำให้หน้าเว็บภายนอกเลื่อนตอนเล่น; ไม่มี horizontal overflow; รองรับ Safe Area (`viewport-fit=cover`)
- WebView ของแอป: ต้องเปิด JavaScript และ DOM storage (`setDomStorageEnabled(true)` บน Android) ถ้าต้องการบันทึกความคืบหน้า

## เพิ่มด่านเอง
แก้ `CUSTOM_LEVELS` ใน `js/levels.js` — แต่ละลูกศรคือรายการช่อง `[col,row]` เรียงจากหางไปหัว ทิศหัวคือทิศของก้าวสุดท้าย
```js
CUSTOM_LEVELS = {
  1: { cols: 5, rows: 5, arrows: [
        [[0,0],[1,0],[2,0],[3,0]],     // ชี้ขวา
        [[0,1],[1,1],[1,2]]            // เลี้ยวแล้วชี้ลง
  ] }
};
```
ด่านที่ไม่ได้กำหนดจะถูกสร้างอัตโนมัติจาก seed (ยากขึ้นตามเลขด่าน: กระดานใหญ่ขึ้นสูงสุด 28×29 และลูกศรยาวขึ้น)
ตัวสร้างด่านวางลูกศรตามลำดับ "นำออก" จึงแก้ได้เสมอ ตรวจซ้ำได้ด้วย
```bash
node tools/verify-levels.js 150
```
ปรับค่าความยากที่ฟังก์ชัน `params(n)`; ปรับจำนวนหัวใจ/คำใบ้/ไม้บรรทัดและความเร็วอนิเมชันที่ค่าคงที่บนสุดของ `js/game.js`

## หมายเหตุด้านเทคนิค
- เรนเดอร์ Canvas 2D; ลูกศรปกติถูกวาดรวมใน path เดียว จึงลื่นแม้ 150+ ลูกศร และตัดส่วนที่อยู่นอกจอ
- ลูปอนิเมชันหลับเมื่อไม่มีอะไรขยับ และหยุดเมื่อแท็บอยู่เบื้องหลัง (กลับมาเล่นต่อได้ปกติ)
- อนิเมชันลูกศร: ถอยตั้งท่า (anticipation) → เร่งความเร็วตามระยะทาง → ไหลตามเส้นโค้งของตัวลูกศรออกนอกกระดานพร้อมจางหาย; ติดขวางจะสั่นเป็นสีแดงพร้อมสั่นเครื่อง (ถ้ารองรับ)
